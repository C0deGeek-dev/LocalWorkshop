# tasks/ — pointer only

LocalWorkshop plans, subjects, and work-tracking live in the **private LocalHub**
repo, not in this public repo (per `LocalX/CLAUDE.md`: docs stay per-project,
but plans/tasks are centralized).

- Per-project plans: `LocalHub/plans/localworkshop/`
- Cross-project plans: `LocalHub/plans/`
- Cross-project task board: `LocalHub/TASKS.md`

A shorthand `tasks/<name>/` reference in a LocalWorkshop skill or doc resolves to
`LocalHub/plans/localworkshop/<name>/`.

Nothing plan-related is committed to this repo — shipped scripts/docs are
plan-agnostic.
